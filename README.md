
Week 6: React.js Fundamentals & Component Development

This repository contains the core projects developed during the React foundations, utilizing modern build tools and advanced React patterns.

Project 1: Personal Professional Portfolio

A responsive personal branding site designed to showcase my skills, projects, and professional journey.

Build Tool: Vite (Optimized for speed and modern development)

Key Features:

Responsive layout for all device sizes.

Dynamic project gallery.

Fast Refresh development environment.

Tech Stack: React.js, Tailwind CSS.




Project 2: Élégance Lady (SheStyle) E-commerce

An intermediate-advanced e-commerce catalog tailored for a luxury brand.

Build Tool: Create React App (CRA)

Key Features:

Product Catalog: Dynamic grid rendering with real-time Search & Category Filtering.

Quick View Modal: High-fidelity product detail overlays.

Persistent Shopping Cart: State synchronized with localStorage.

Validated Checkout: Multi-step process with Form Validation.

Technical Implementation:

Lifting State Up: Global cart state shared across components.

Conditional Rendering: Smooth transitions between the "Bag view" and "Shipping form."

Getting Started:

For the Portfolio (Vite)


**cd my-portfolio
npm install
npm run dev**

For Élégance Lady (CRA)


cd elegance-lady-shestyle
npm install
npm start
